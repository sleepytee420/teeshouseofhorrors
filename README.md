TEE'S HOUSE OF HORRORS — CINEMATIC V2

HOW TO TEST
Open index.html in Chrome/Firefox. Turn sound on and click KNOCK.
Use Reset door for each new paid knock.

HOW TO UPDATE GITHUB PAGES
Upload index.html AND the entire assets folder to the ROOT of your teeshouseofhorrors repository.
The folder structure must be:
  index.html
  assets/entrance.webp, mansion.webp, facade.png, door.png, ghost.webp, ...
If your old entrance.png file is still there, it can stay; this version doesn't use it.

HOW IT WORKS
7 gaming prizes have equal odds of 88/7% each (12.5714%).
2 movie prizes have equal odds of 6% each.
A random prize is chosen when KNOCK is clicked, not when the website loads.
The reveal uses your approved artwork, not icons or CSS monster drawings.
The opening door is a separate cropped layer with its right hinge anchored.

NOTES
The door sprite is derived from a flattened entrance illustration, so this is a 2.5D illusion rather than a true 3D animated door.
Sound is generated in the browser; share the browser tab with audio enabled in Discord.
